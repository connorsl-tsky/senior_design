# Design Contraints Essay
Project: Computer Vision ASL Learning Tool  
Team Members: Braden Monnin, Isaac Dowdy, Connor Slutsky

## Security
  Arguably the clearest design constraint for this project lies in the realm of security. Since we are developing a computer vision tool for ASL learners, our application will need to access a user's camera. The application should store and process any recorded content within the software without sending data to any external services, even though this might limit different computer vision or data storage methods.

## Ethics
  Another constraint area for this project is ethical, similarly due to the possibility of gathering user data to train a machine learning model. Users should be given clear explanation of this and a choice to opt-in or out before we begin recording or storing any data. A trade-off exists here because collecting more user data could produce a higher-quality model but place strain on security, while collecting less data would better protect users' privacy and reduce security risks.

## Diversity and Culture
  Finally, ASL is a language with important cultural context, making Diversity and Cultural considerations all the more relevant to our project. We must be aware of the intended users of our application and the different styles, backgrounds, and experiences they may bring to learning ASL. ASL is a complete language, like any language, has great depth, and it is important that we remain aware of this. Designing the application around clear feedback and usability is important to serve our users well and create a product that supports accessibility while recognizing the depth of the language.
